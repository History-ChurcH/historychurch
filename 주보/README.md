# 주보 올리는 곳

이 폴더에 **주일 날짜로 시작하는 이름**의 주보 이미지나 PDF 를 올리면, 1~2분 뒤 홈페이지 주보 목록에 자동으로 나옵니다.

| 이렇게 이름 짓기 | 결과 |
| --- | --- |
| `2026-10-11-1.jpg`, `2026-10-11-2.jpg` | 10월 11일 주보 (1면, 2면 순서로 보임) |
| `2026-10-11.pdf` | 10월 11일 주보 (PDF) |

- 같은 날짜의 파일은 주보 하나로 묶입니다. 이미지와 PDF 를 함께 올려도 됩니다.
- 400KB 가 넘는 jpg·png 는 몇 분 안에 자동으로 WebP 로 줄어듭니다. (이름 끝이 `.webp` 로 바뀌는 것이 정상입니다)
- 예전 주보(2026년 10월 4일까지)는 `public/uploads/bulletins` 폴더에 그대로 있습니다. 새 주보는 이 폴더에 올려 주세요.
- 자세한 방법은 저장소 맨 위의 `업로드_가이드.md` 를 보세요.
